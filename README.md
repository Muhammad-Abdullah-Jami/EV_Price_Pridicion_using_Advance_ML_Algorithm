## Project Overview

This repository contains an end-to-end electric-vehicle (EV) price-prediction pipeline. I collected and preprocessed EV data, trained and tuned four regression models, and documented my findings in a research paper. The notebook fetches all data via API calls—no local CSV is required.

---

## Key Deliverables

- **Notebook**: `Electric_car_price_prediction.ipynb`  
  - Fetches data programmatically  
  - Performs EDA, preprocessing, model training & tuning (Linear Regression, Random Forest, XGBoost, SVR)  
  - Evaluates performance (MAE, MSE, RMSE, R²)  
  - Serializes the best model for inference  

- **Research Paper**: `Comparative analysis of Machine Learning M....docx`  
  - Full write-up of methodology, hyperparameters, results, and conclusions
